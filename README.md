# Тестовое задание

**Стек:** Vite, TypeScript, Less, БЭМ

## Реализовано
- Адаптивный layout страницы
- Мобильное меню: анимация, блокировка скролла, закрытие по клику вне
- Два варианта сетки карточек:
    - фиксированное число колонок + скрытие незаполненного ряда
    - auto-fit + скрытие незаполненного ряда
- CSS-переменные, миксины сетки, SVG-спрайт (SVG символы в вёрстке через use, удобно анимировать fill и stroke)
